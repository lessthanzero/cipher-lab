# Dorabella Cipher Project

- **Origin**: Edward Elgar's letter to Dora Penny (July 14, 1897).
- **Corpus**: 87 characters in 3 lines, drawn from 24 distinct symbol variants (1, 2, or 3 semicircular humps in 8 orientations).
- **Epistemic Invariant**: Simple substitution unicity distance $U_0 \approx 25$ chars, but polyalphabetic or homophonic cipher spaces have $U_0 > 100$ chars. The pipeline enforces twin-negative controls to prevent false-positive "phonetic pun" decryptions.
