# Shugborough Inscription Project

- **Origin**: Shepherd's Monument, Shugborough Hall, Staffordshire (c. 1748–1756).
- **Corpus**: `O U O S V A V V` with `D` and `M` on lower/flanking tiers (8 letters).
- **Mathematical Bound**: $N = 8 \implies < 38$ bits of information. Unicity distance is severely violated ($N \ll U_0$).
- **Epistemic Invariant**: Mathematically underdetermined. Single-key cryptanalysis is formally prohibited; system strictly enforces epistemic abstention. Historical/epigraphic motif index only.
