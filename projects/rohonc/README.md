# Rohonc Codex Project

- **Origin**: Central Europe / Batthyány family library, Rohonc (Rechnitz), donated to Hungarian Academy of Sciences in 1838.
- **Dating**: Venetian paper with Anchor and Anchor-in-circle watermarks c. 1530–1540.
- **Corpus**: 448 pages (~87,000 characters, ~150 core signs expanding to ~790 variants with ligatures).
- **Consensus**: Breakthrough work by Levente Zoltán Király (2010) and Gábor Tokai (2010, 2018) established that the codex is an early modern Christian tachygraphic shorthand/codebook system encoding liturgy and biblical texts (likely Hungarian/Latin).
- **Research Value**: High-signary codebook matrix alignment, liturgical incipit crib search, structural repetition clustering.
